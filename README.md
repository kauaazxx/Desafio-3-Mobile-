# ⛽ Abastecimento de Veículos

Aplicativo desenvolvido em **Flutter** para acompanhar o histórico de abastecimentos de um veículo. O aplicativo permite adicionar, editar e excluir abastecimentos, calcular o preço médio por litro, o consumo médio do veículo e visualizar um gráfico comparativo dos registros.

---

## ✨ Funcionalidades

* ➕ **Gestão de Abastecimentos**: Permite adicionar, editar e excluir registros.
* ⛽ **Tipo de Combustível**: Registro do combustível utilizado em cada abastecimento.
* 💰 **Preço Médio**: Cálculo automático do valor médio pago por litro.
* 🚗 **Consumo Médio**: Cálculo do rendimento do veículo (km/L).
* 📊 **Gráfico Comparativo**: Visualização gráfica e comparativa de todos os abastecimentos.
* 💾 **Persistência de Dados**: Armazenamento local para salvar o histórico no dispositivo.
* 🎨 **Interface Personalizada**: Design customizado nas cores vermelho e creme.

---

## 🛠️ Tecnologias Utilizadas

* [Flutter](https://flutter.dev/) - Framework UI para desenvolvimento multiplataforma.
* [Dart](https://dart.dev/) - Linguagem de programação principal.
* **Chart.js** / **HTML** / **CSS** - Visualização de gráficos e estilização.
* **JSON** - Estruturação para manipulação dos dados.
* **Armazenamento Local** - Persistência dos dados no dispositivo.
